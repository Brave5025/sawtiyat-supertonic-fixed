# صوتيات — Sawtiyat

مشروع مستقل لتطوير تطبيق صوتيات العربي وتحسين جودة النطق باستخدام محرك Supertonic.

## حالة المشروع

هذا المستودع جديد ومستقل عن المستودع السابق. لم يُرفع مصدر التطبيق بعد، ولم يُنتج APK من هذا المستودع حتى الآن.

## المصدر المعدّل

سيُضاف مصدر Android المعدّل بعد نقله إلى هذا المستودع، ثم تُضبط عملية البناء والتحقق عبر GitHub Actions.

## تنبيه

لا تعتبر أي نسخة APK جاهزة أو مختبرة حتى تنجح عملية البناء الفعلية وتُتحقق من ملف APK الناتج.
